# 三导演视频风格改写

一个 Codex Skill，用于按需生成王家卫、李安、韦斯·安德森三种风格的 AI 视频提示词。支持单独调用、连续切换、两版或三版对比，以及实拍视频的人物、场景、道具和镜头改造。

## 使用

把本仓库安装到 Codex 的 `skills/director-style-video` 目录，然后在聊天中输入：

```text
$director-style-video 用王家卫风格改写这个视频，保留主角五官和核心动作，重新设计服装、场景、氛围与运镜。
```

将“王家卫”替换成“李安”或“韦斯·安德森”即可。也可输入“同一段视频三个风格各写一版”。具体规则见 [SKILL.md](SKILL.md)。

技能默认只编写提示词，不提交视频生成任务。导演档案是创作参考，不保证模型生成结果与任何特定电影完全相同。资料来源和现成技能的边界见 [sources.md](references/sources.md)。仓库不包含第三方技能代码或用户视频素材。
