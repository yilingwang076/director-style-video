# 维护时的行为评估

这些案例用于检验决策，不用固定措辞匹配。结构校验或文字走查不能证明实际生成视频的风格相似度。

| 输入情境 | 应出现的行为 | 应避免的行为 |
| --- | --- | --- |
| “用王家卫风格写雨夜等车” | 仅一版王家卫，设计等车情境，自动选择合适方向 | 输出三版，或自动添加伏击与枪械 |
| “再换成李安” | 沿用素材和明确锁定项，重新设计该导演的视听与表演 | 残留上一版未锁定的霓虹、拖影及独白 |
| “李安和韦斯安德森各一版” | 按指定顺序给两份完整提示词 | 自动添加王家卫或混合两位导演 |
| “王家卫光色＋韦斯构图” | 明确分层使用，选择一致的镜头运动 | 同时要求稳定正面和高速环绕 |
| “同一个墙后伏击，分别王家卫、李安、韦斯；保留脸，可换场景服装镜头” | 分别选择夜间窄空间、克制悬念、正面秩序等具体设计；同一事件三份独立提示词 | 三份相同机位和衣服，只改颜色 |
| “韦斯风格，但服装、废墟、环绕镜头都不能变” | 保留锁定项，利用现有画面的物件和色块组织，解释完整正面构图受限 | 同时要求固定正面和完全保留环绕 |
| “李安《少年派》那种明亮奇幻海面” | 路由至自然奇观，查看相关参考，设计环境与反射 | 直接复用灰暗室内伏击 |
| “手里鞋垫变枪但保留动作” | 保持持握点运动，重建枪体、手指与露出的背景 | 保留鞋垫轮廓或强迫枪体贴合其椭圆形状 |
| “3秒视频，把开枪改成告别、犹豫、回忆、决断再开枪” | 指出时长容量，给三秒可行版本或明确标注的加长方案 | 编造三秒内完整多场戏并宣称可实现 |
| “只能改滤镜，别碰其他” | 限定光色/纹理调整，交付相应范围 | 自动换装、重新布景、生成新镜头 |
| 视频文件读取失败但有用户动作描述 | 按描述写并说明依据，不给伪造精确时刻 | 声称逐帧看过 |
| “提示词写好，直接给我复制” | 提供一个完整代码块和必要的素材映射 | 自动上传与付费生成 |

## 视觉验证建议

取得真实生成结果后再评价：构图/摄影位置、布景/造型、光线/色彩、动作/时间、道具连续性分别记录可见证据。相似度不足先定位层级，再修改对应规则；避免根据一次失败扩大成平台或导演的普遍结论。

只有图像结果时只能报告静态画面检查；音效与运动需视频验证。没有生成结果时明确“尚未进行生成验证”。
